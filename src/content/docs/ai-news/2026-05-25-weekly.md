## 论文精选

### DelTA，基于可验证奖励的强化学习判别式 Token 信用分配

**社区热度 192** · [查看论文](https://arxiv.org/abs/2605.21467)

论文从判别器视角分析可验证奖励强化学习（RLVR）的更新过程，解释响应级奖励如何转化为 Token 级概率变化。其信用分配方法可用于分析 RLHF 和 RLAIF 的训练稳定性与效率。

### SkillOpt，自进化 Agent 技能的执行策略

**社区热度 159** · [查看论文](https://arxiv.org/abs/2605.23904)

现有 Agent 技能多由人工编写或一次性生成，缺少稳定的反馈改进机制。论文把技能视为冻结 Agent 的外部状态，并用优化策略持续更新技能。

### LocateAnything，通过并行框解码实现快速、高质量的视觉语言定位

**社区热度 93** · [查看论文](https://arxiv.org/abs/2605.27365)

### π-Bench，评估长周期工作流中的主动式个人助理 Agent

**社区热度 91** · [查看论文](https://arxiv.org/abs/2605.14678)

该基准关注 Agent 处理模糊需求和长周期任务时的主动性，评估它能否主动澄清问题并识别约束。

### Lens，重新思考基础文生图模型的训练效率

**社区热度 90** · [查看论文](https://arxiv.org/abs/2605.21573)

Lens 是一个 3.8B 参数的文生图模型。论文报告称，它在部分指标上达到或超过 6B 参数模型，训练算力约为后者的 19.3%。

## 开源项目

### esengine/DeepSeek-Reasonix

[查看仓库](https://github.com/esengine/DeepSeek-Reasonix)

这是一个基于 DeepSeek 的编码 Agent 框架，重点利用上下文缓存减少高频交互时的 API 调用成本。

### openclaw/openclaw

[查看仓库](https://github.com/openclaw/openclaw)

这是一个支持多渠道接入的开源个人助理 Agent 框架。该版本优化了网关性能，并加入基于表情的快捷权限审批。

### datasette/datasette-agent

[查看仓库](https://github.com/datasette/datasette-agent)

这是 Datasette 的可扩展 AI 助手插件，可把 LLM 的自然语言转 SQL 能力接入现有的数据探索流程。
